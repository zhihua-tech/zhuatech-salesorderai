# 企业级销售订单放行治理

销售订单进入履约前，需要同时检查信用冻结、受限方筛查、库存、价格授权、承诺交期和合同条款。本模块提供统一放行门禁，避免 AI 建议或人工操作绕过关键控制。

`POST /api/enterprise/sales-orders/release-governance` 返回 `RELEASE / HOLD / APPROVAL_REQUIRED` 决策、全部阻断项和处置动作。受限方筛查与合同条款属于不可绕过控制；其他业务例外即使完成例外审批，仍进入最终授权确认，不直接自动放行。

生产部署应进一步关联客户信用、库存 ATP、定价策略、合同版本、审批权限和全量审计日志。DeepSeek 等模型仅可用于辅助识别与解释，不可替代确定性放行规则。
